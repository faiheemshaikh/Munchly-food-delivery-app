# 🍔 Munchly — Online Food Delivery Web Application

Munchly is a Java-based food delivery web application inspired by platforms such as Swiggy and Zomato. It allows customers to discover restaurants, explore menus, manage their shopping carts, place food orders, and view their order history and status.

The application also features an administrative panel for managing restaurants, controlling menu and item availability, viewing dashboard statistics, and updating order statuses.

## ✨ Key Features

### 👤 Customer Features
- User registration and login
- Restaurant browsing and cuisine discovery
- Menu browsing with food images and prices
- Shopping cart management and checkout
- Food order placement and order history
- Order status and order-detail viewing
- Customer profile management

### 🛠️ Admin Features
- Admin dashboard with platform statistics
- Restaurant creation and editing
- Restaurant activation and deactivation
- Menu and item availability management
- Order monitoring and status updates

## 🛠️ Technology Stack

- **Language:** Java 17
- **Backend:** Jakarta Servlets
- **View Technology:** JSP, JSTL and Expression Language (EL)
- **Database Connectivity:** JDBC
- **Database:** MySQL 8+
- **Build Tool:** Maven (WAR)
- **Application Server:** Apache Tomcat 10.1 (Jakarta Servlet 6.0, JSP 3.1, JSTL 3.0, uses `jakarta.*`)
- **Architecture:** MVC + DAO
- **Passwords:** BCrypt (`at.favre.lib:bcrypt:0.10.2`, cost 12)
- **IDE:** Eclipse IDE

Munchly demonstrates Java web development through a structured MVC architecture, database integration, session management, and role-based access control.
