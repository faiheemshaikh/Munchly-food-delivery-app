# Image Manifest

All paths are relative to `src/main/webapp/`. The database stores them exactly as written below.

**If a file is missing, the page still works**: every `<img>` falls back to `images/placeholder.svg` (added in Phase 5).

Use only images you are licensed to use (your own photos, or free-licence sources such as Unsplash/Pexels/Pixabay, which you download yourself). Suggested size: restaurants 800x500 px, food 600x400 px, JPG, under 200 KB each.
